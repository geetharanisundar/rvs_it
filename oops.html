ios::app vs ios::ate

                
What is the critical technical distinction?

              

              
Tap to flip & reveal model answer

            


            
            

              

                EXAM SPECIFICATION
                Answer
              

              

                

                  ios::app forces ALL writes to the end of file exclusively; write pointer cannot be moved backward.


                  ios::ate ("at end") opens the file and positions write pointer at the end once, but allows you to seek back to any arbitrary byte location!
